# Kareem & Raneem — Digital Gift

موقع Single Page بدون مكتبات خارجية. افتح `index.html` بعد فك الضغط (أو `single-file.html` وهو نفس الموقع في ملف واحد والأغنية مدمجة فيه).

## التعديل
كل البيانات في `CONFIG` أعلى ملف `js/script.js`:
- `girlBirthday`: استبدل `RANEEM_BIRTHDAY` بتاريخ ميلاد رنيم بصيغة `YYYY-MM-DD` (ما دام فاضي بيظهر "Soon ❤️").
- `songArtist`: اسم الفنان (اختياري).
- `password`: كلمة المرور (بتقبل 10/11 و10-11 و10.11 والأرقام العربية).

## الأغنية
حط ملف الأغنية في `assets/music/song.mp3`. لو الملف مش موجود المشغل بيظهر ملاحظة ومفيش خطأ في الموقع.
